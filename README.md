# 💱 Currency Converter

A responsive Currency Converter web application built using HTML, CSS, and Vanilla JavaScript.

The application fetches live exchange rates from the ExchangeRate API and allows users to convert between different currencies with real-time results.

---

## 💼 Project Type

Personal Frontend Project

Built to practice API integration, asynchronous JavaScript, DOM manipulation, and dynamic UI updates.

---

## ✨ Features

- Real-time currency conversion
- Live exchange rates using ExchangeRate API
- Convert between multiple international currencies
- Dynamic country flag updates
- Input validation
- Responsive user interface
- Instant conversion results

---

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Fetch API
- ExchangeRate API
